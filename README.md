# Transfer Knowledge from CLIP to Lightweight CNN model using VL2Lite architecture
[VL2Lite](https://github.com/jsjangAI/VL2Lite) introduced by Jang et al. 2025<sup>1</sup>


 is a Vision-Language Knowledge Distillation framework designed to transfer rich, multi-modal semantic knowledge from large-scale foundation models into lightweight, compute-efficient convolutional vision backbones.
